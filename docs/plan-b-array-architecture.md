# 红岸三号 · Plan B 阵列结构细化 (v3)

> 依据极客湾实测 (YouTube cUrFGNdgYwI, 小米 12S Ultra / IMX989 魔改可换镜头相机)。
> **核心方法**: PCB 和 sensor 模组**都不用改** — 保持原连接不动, 只 3D 打印一个**新底座/中框**, 把整个"主板+模组"总成重新摆位, 让 sensor 光轴移到镜头卡口中心。

## 〇、极客湾的实际做法 (纠正 v2 的错误)

v2 误以为要"拆下 sensor 模组、延长排线、自由摆放"。**实测并非如此:**

1. 暴力拆除**镜头模组**的金属防滚架 + 外壳 → 暴露裸 CMOS (sensor 模组本身留在排线上, 不动)
2. 主摄原本**不在机身居中** (在中线左边), 直接装机壳卡口会超出边框、强度也不够
3. 于是给**整个中框 3D 扫描建模** → 丢掉原中框 → **3D 打印一个自设计的新中框/前壳**
4. 把**主板 (连带着排线上的 sensor 模组)** 装到新打印的底座上, **重新布局安装槽位**, 让 sensor 光轴对准镜头卡口中心
5. 用**螺丝 + 橡胶垫圈**固定 CMOS 并**微调法兰距** → 保证光学正常
6. 舍弃原电池, 只留保护板, 改 **18650 电池包**供电
7. 机身留标准螺纹孔, 装三脚架等配件

**关键**: PCB ↔ sensor 模组的**电气连接完全不动** (排线原样), 只是通过 3D 打印的新机械底座把整个总成**重新定位**。没有拆排线、没有延长排线、没有独立摆放 sensor。

## 一、单节点结构 (v3)

```
        天文镜头 (如 Samyang 135mm f/2.0, 或 Sony E 卡口镜头)
                    │
        ┌───────────▼─────────────┐
        │  卡口环 (E卡口/EF, 拆机件)  │  闲鱼拆机卡口, 便宜
        ├─────────────────────────┤
        │  3D 打印的新底座/中框      │  ← 核心定制件
        │  · 重新定位主板+模组总成    │
        │  · 让 sensor 光轴居中到卡口 │
        │  · 螺丝+橡胶垫圈微调法兰距   │
        ├─────────────────────────┤
        │  裸 CMOS (IMX989)         │  ← 已拆除原镜头/防滚架
        │  (sensor 模组, 排线原样)    │
        ├─────────────────────────┤
        │  手机主板 (原样, 不改)       │  SoC+ISP+存储+USB
        │  只去电池, 留保护板          │
        ├─────────────────────────┤
        │  18650 电池包 / 统一供电     │
        └─────────────────────────┘
```

### 与 v2 的区别
| | v2 (错误) | v3 (正确) |
|---|---|---|
| sensor 模组 | 拆下, 延长排线, 自由摆放 | **不拆, 排线原样, 随主板整体重新定位** |
| PCB | 只保留核心, 重新布局器件 | **原样不动** |
| 定制件 | 转接环 + 延长排线 + 节点卡片 | **就一个 3D 打印底座/中框** |
| 对准方式 | 位移台逐颗调 | **螺丝+橡胶垫圈微调法兰距** |
| 主要风险 | MIPI 排线延长信号完整性 | **3D 打印精度 (底座平面度/卡口同轴度)** |

## 二、阵列 (Array) 结构

### 单一托架, 紧密网格
32 个节点 (每个 = 主板+模组+3D 打印底座+卡口+镜头) 固定在一个便携托架上:

```
   ┌──────────────────────────┐
   │  ○ ○ ○ ○ ○ ○             │   ○ = 一个完整节点 (含 3D 打印底座)
   │  ○ ○ ○ ○ ○ ○             │   8×4 = 32 镜, 同指一天区
   │  ○ ○ ○ ○ ○ ○             │
   │  ○ ○ ○ ○ ○ ○  (留中心孔)   │
   └──────────────────────────┘
   背面: 统一供电母线 + USB Hub + 控制主机
```

### 结构分层
```
┌─ 前层: 32 × 镜头 + 卡口 (光学面)
├─ 中层: 32 × 3D 打印底座 (定位 sensor 到卡口中心)
├─ 后层: 32 × 手机主板 (统一散热风道)
├─ 底层: 18650 电池包阵列 / 12V DC + USB Hub + 控制主机
└─ 底座: 赤道仪接口 (Vixen/Losmandy 鸠尾板)
```

## 三、统一供电
- **18650 电池包** (移动/野外, 如冷湖) 或 **12V DC 母线** (固定台址)
- 所有节点共地, 避免地环路噪声
- 每个节点只留保护板, 不带独立电池 → 集中充放电管理

## 四、统一控制 — ADB over USB
```
   控制主机 (RK3576 / 树莓派 / 笔记本)
        │ USB 3.0 Hub 级联
   ┌────┼────┬──── ... ────┐
   ▼    ▼    ▼             ▼
 节点1 节点2 节点3   ...   节点32  (各经 ADB)
```
- **同步触发曝光**: 广播指令, 各节点本地计时 (秒级同步即可, 后期星点对齐)
- **参数下发**: 曝光/增益/无穷远, Camera2 API 自研 APP, ADB 推送
- **RAW 拉取**: `adb pull` / socket 直传 DNG
- **状态监控**: 温度/电量/存储
- root 后: 关 ISP 降噪, 拿干净 RAW (参考极客湾 — 只能拍 RAW, 反而正是红岸要的)

## 五、数据流 + 校正帧 (解决极客湾翻车点)
```
节点 RAW → 控制主机 → 叠加管线
   ├─ 每节点一组校正帧 (一次性拍摄, 复用):
   │   Bias (偏置) / Dark (暗场) / Flat (平场)
   │   → 修掉 Lens Shading / 热像素 / 暗电流
   ├─ 星点对齐 (Astrometry.net / 自研)
   └─ 32 节点 × N 帧叠加 → 深空图像
```

## 六、相比整机堆叠的优势
| 维度 | 整机堆叠 | 3D 打印底座节点阵列 |
|---|---|---|
| 体积/重量 | 笨重 | 紧凑单托架 |
| 定制件 | 整机外壳改造 | **就一个 3D 打印底座** |
| 电气 | 不动 | 不动 (PCB+排线原样) |
| 供电 | 32 电池分散 | 统一 18650/DC |
| 控制 | 逐台操作 | ADB 集中可编程 |
| 成本 | 整机价 | 料板价 + 打印件 |

## 七、开放工程问题 (v3 修正后)
1. **3D 打印底座的平面度/同轴度** — sensor 光轴要对准卡口中心 + 法兰距 ±0.1mm + 倾斜 <0.05°。PLA 打印件能否稳定hold住这个精度 (温度/蠕变), 是主要风险。关键配合面或需 CNC 金属件。
2. **法兰距微调机构** — 螺丝+橡胶垫圈能否调到 ±0.1mm 并长期稳定 (极客湾做到了能用, 但"不严丝合缝" → 星点边缘画质)。
3. **多手机 ADB 并发** — 32 台同时 ADB, USB Hub 拓扑/供电/驱动稳定性需实测。
4. **同步精度** — 各节点曝光起始时间差 (后期可校正, 越小越好)。
5. **散热** — 开放后层可加风道/Peltier, 32 主板集中发热的温控设计。
6. **料板一致性** — 32 块同型号同批次 (IMX989), 保证校正帧可复用。
