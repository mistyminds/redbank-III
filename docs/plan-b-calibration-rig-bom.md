## 校准流程 (每颗 sensor)

1. 加热平台 80–120°C 软化 UV 胶 → 显微镜下撬下镜头模组
2. 裸 sensor 模组固定到 5 维位移台 → 接天文镜头转接环
3. 平行光管产生无穷远星点 → 实采图
4. 调 XYZ + 俯仰/偏摆, 用 MTF Mapper 监测, 找 MTF/星点最锐峰值 = 焦点
5. UV 胶点胶 → UV 灯固化锁死

**工时: 每颗约 0.5–2 小时 (熟练后趋向下限)。32 颗 ≈ 16–64 小时。**

## 成本摊销 (32 镜阵列)

- 校准台一次性投入 ~¥1.5–3万 (取中值 ~¥2万 ≈ $2,800)
- 摊到 32 颗: **每颗 ~¥500–900 (~$70–125)**
- Plan B 单台硬件省 $618 vs Plan A $1,600 → 32 颗省 ~$31,000
- **净省: ~$31,000 − $2,800 (校准台) ≈ $28,000, 代价是 ~16–64 小时校准工时**

> 结论: 若确定走 Plan B, 这套一次性校准台**值得投入**。
> 若只做 4 镜以下小规模, Plan A (零校准投入) 反而更省。
